# DevShare（技享）需求分析文档（PRD）

## 1. 背景与目标

面向开发者的技术内容社区。核心价值：**高质量技术内容的生产、发现与讨论**。

目标：

- 从 0 到 1 交付一个可上线的最小完整产品（标准版）；
- 首页与文章详情服务端渲染，保证首屏速度与 SEO；
- 长列表（信息流/评论）虚拟滚动，保持滚动性能；
- 中英双语，国内云部署 + CDN 全球加速。

## 2. 用户画像

- **读者**：搜索/浏览技术文章，按标签筛选，点赞收藏评论；
- **作者**：发布/编辑/草稿文章，管理自己的内容；
- **访客**：未登录浏览全部公开内容，登录后互动。

## 3. 功能清单（标准版 v1）

| 模块   | 功能                                                              |
| ------ | ----------------------------------------------------------------- |
| 账号   | 注册、登录、登出、刷新令牌、个人资料编辑（用户名/简介/头像/语言） |
| 文章   | 发布、草稿、编辑、删除（仅作者/admin）、Markdown 渲染、标签、封面 |
| 信息流 | 最新 / 热门排序、标签过滤、游标分页、无限滚动（虚拟滚动）         |
| 互动   | 点赞、收藏、评论（含回复）、浏览计数                              |
| 关系   | 关注 / 取消关注，粉丝与关注数                                     |
| 搜索   | 文章与作者全文检索（Meilisearch，DB 兜底）                        |
| 榜单   | 热门榜（时间衰减 + 互动加权，Redis 缓存，每小时重算）             |
| 国际化 | 中 / 英双语，URL 前缀`/zh` `/en`，默认跟随浏览器语言              |
| 课程   | 精品课程板块、详情页、公益免费报名、课程与讲师管理                |
| 运营   | 首页 Banner 轮播，标题 / 副标题 / 图片 / 跳转地址由后台配置       |

### 3.1 课程模块（v1 增量）

- 首页「精品课程」板块：分类 tab（推荐 + 动态分类）+ 3×2 卡片网格 + 「加载更多」，右栏「热门方向」列表与左侧 tab 双向联动；
- 课程详情 `/courses/:id`：封面、标题、角标、难度、报名人数、讲师卡（头像 + 姓名 + 简介）、适合人群、课程简介与报名入口；
- 报名：全部课程为公益免费课程，登录后一键报名、无需支付；取消报名保留记录并置为 `canceled`，可再次报名；报名人数按有效记录实时统计；
- 报名记录：顶栏用户菜单「我的课程」与课程详情页侧栏（报名后出现）都指向个人主页「课程」tab（`/user/:id?tab=courses`，tab 与地址栏同步），接口 `GET /users/:id/courses` 与入口一样仅本人可见；
- 后台：课程与讲师增删改查、课程上下架、报名名单查看（仅管理员）；
- 边界：课程分类复用文章标签表，首页 tab 只展示含已上架课程的标签，排序与站内标签导航一致（`DEFAULT_TAGS` 优先、其余按名称）；课程不接入搜索 / 热门榜，也不单独做课程列表页（首页「加载更多」承担）。

### 3.2 首页 Banner（v1 增量）

- 首页顶部轮播改由后台配置驱动：标题（必填）、副标题、图片（必填）、跳转地址（必填，站内路径或 `http(s)` 外链）、排序值、启用开关；
- 公开接口只返回启用项并按排序值倒序；后台 `/admin/banners` 提供增删改查与启用停用（仅管理员，入口在用户菜单）；
- 未配置任何启用 Banner 时首页顶部整块不渲染，页面直接从「精品课程」开始。

## 4. 信息架构

```
DevShare
├── 首页（SSR）          Banner | 推荐信息流 | 精品课程 | 热门榜 | 标签导航
├── 文章详情（SSR）      正文 | 操作栏（点赞/收藏/评论）| 评论列表 | 作者卡
├── 课程详情 /courses/:id  封面 | 讲师卡 | 适合人群 | 课程简介 | 报名
├── 标签页 /tag/:slug     该标签下的文章流
├── 搜索 /search          文章 / 作者 双 tab
├── 个人主页 /user/:id    资料卡 | 文章 / 收藏 / 课程（仅本人）
├── 写文章 /write         标题、摘要、封面、标签、Markdown 编辑器
├── 个人设置 /settings    资料、头像上传、语言
├── 登录 / 注册
├── 后台 /admin/*        标签 | 课程 | 讲师 | Banner 管理（仅管理员）
└── 组件预览 /dev/components
```

## 5. 非功能需求

- **性能**：首页 SSR TTFB < 300ms（缓存后）；首屏 JS ≤ 200KB（gzip）；信息流 1000+ 条滚动 60fps。
- **SEO**：首页/文章详情 SSR + SWR 缓存 + hreflang 双语文档。
- **安全**：bcrypt 密码、JWT 30 分钟 + Redis 刷新令牌 7 天、XSS 净化（markdown-it + sanitize-html）、限流、CORS 白名单、上传类型/大小限制。
- **可维护性**：pnpm monorepo、共享类型包、Swagger 文档、单元测试与关键路径 E2E。

## 6. 验收标准

1. 注册 → 登录 → 写文章 → 发布 → 首页可见 → 评论 → 点赞收藏，全链路可用；
2. Swagger 全部接口可调通，权限校验正确；
3. 中英切换无漏翻，hreflang 正确；
4. Lighthouse 移动端 ≥ 90；
5. 生产环境 HTTPS + CDN 生效，静态资源命中率 ≥ 90%。
6. 课程：首页板块筛选与「加载更多」可用、公益免费报名与取消可用、后台课程与讲师管理及报名名单可用。
7. 首页 Banner：后台可增删改与启用停用，首页只展示启用项并按排序值倒序，站内 / 外链跳转正确，全部停用后首页顶部整块隐藏。

## 7. 里程碑

1. 环境与 monorepo 骨架
2. 设计系统 + 高保真原型
3. 后端 API + 数据库
4. 前端页面 + 性能优化
5. 联调 + 测试
6. 备案 + 部署上线
